# AgentBox

[English](README.md) | [简体中文](README_CN.md) | **Русский**

AgentBox запускает Claude Code и Codex CLI на вашем Linux-сервере. Чат, терминал, файлы и Git доступны в браузере. Для каждого рабочего пространства AgentBox создаёт отдельный Docker-контейнер.

## Установка

Для штатной установки нужен Linux x86-64 или ARM64 с systemd и Docker Engine. Установщик скачает стабильный релиз форка, соберёт образ рабочего пространства и запустит службу `agentbox.service`.

```bash
curl -fsSL https://raw.githubusercontent.com/zyclonite135/agentbox/refs/heads/feature/my-change/install.sh | sudo bash
```

Для длительного доступа через интернет настройте HTTPS. [Руководство по развёртыванию](deploy/README.md#https-与-websocket-反向代理)

## Первый вход

1. Откройте `http://IP_СЕРВЕРА:8180` в браузере. На странице входа выберите **Русский**.
2. Войдите под именем `boxadmin`. Начальный пароль установщик выводит в терминале по завершении установки.
3. В разделе **Настройки → Аккаунты** подключите Claude или Codex. Создайте рабочее пространство с пустым проектом, загрузите архив или импортируйте Git-репозиторий.

Если вы пропустили начальный пароль, на сервере со стандартной установкой его можно прочитать из поля `auth_token`.

```bash
sudo python3 -c 'import json; print(json.load(open("/etc/agentbox/config.json"))["auth_token"])'
```

Если вы сменили начальный пароль и забыли новый, его можно сбросить. [Как сбросить пароль администратора](docs/troubleshooting.md#忘记密码或改了-auth_token-仍不能登录)

## Обновление

Войдите как администратор и откройте **Настройки → О программе и обновления → Проверить обновления**. Когда доступен более новый стабильный релиз форка, на штатной установке Linux/systemd появится кнопка **Обновить и перезапустить**. [Релизы форка](https://github.com/zyclonite135/agentbox/releases)

Для локальной проверки в Docker пересоберите серверный образ и запустите новый контейнер с прежним томом данных. Для ручного обновления Linux используйте пакет из релиза форка. [Ручная установка и обновление](deploy/downloads/README.md#手工安装与升级)
